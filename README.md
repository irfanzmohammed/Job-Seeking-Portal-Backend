# Job Seeking Portal - Backend

**Frontend repository:** https://github.com/irfanzmohammed/Job-Seeking-Portal.git

REST API for a full-stack job portal with separate job seeker and recruiter roles. This repository contains the **backend** (Node.js, Express.js, MongoDB). The React.js frontend is in the repository linked above.

## Features
- REST APIs for job seeker and recruiter roles
- Data storage for users, profiles and job listings in MongoDB
- Support for skill-based job matching, based on the skills in a job seeker's profile
- Support for campus recruitment drives posted by recruiters, with direct apply links for students

## Tech Stack
- Node.js
- Express.js
- MongoDB
